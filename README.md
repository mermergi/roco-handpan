# 手碟自动演奏

游戏里手碟的自动演奏工具。导入一份谱子，它按你校准好的琴键位置，自动帮你点。

不用 root，不用电脑。

## 下载

到 [Releases](../../releases/latest) 下载 `handpan-autoplay.apk`。

## 安装

安装时系统可能提示「未知来源」，允许即可。

打开后按提示做三步，缺一不可：

| 步骤 | 怎么做 |
|---|---|
| ① 悬浮窗权限 | 点【授予悬浮窗权限】→ 允许 |
| ② 无障碍服务 | 点【开启无障碍服务】→ 在列表里打开「手碟自动演奏」 |
| ③ 校准琴键 | 点【校准琴键】→ 切到游戏 → 依次点 9 个琴键的**正中心** |

九个键的位置：上排 `高音1 高音2 高音3`，中排 `中音3 中音4 中音5 中音6 中音7`，下排 `低音6`。

> 弹出「受限设置」就点系统菜单里的**允许受限设置**。
>
> 小米 / HyperOS 可能还要在 应用信息 里允许「自启动」和「后台弹出界面」。

## 使用

**主页面**

顶上显示当前曲目，**下面紧跟着全部演奏参数和两个按钮**：

- 调性 / BPM / 速度 / 和弦上限 / 按八度自动选键——**改完下面预览立刻刷新，所见即所弹**
- 【自动解析】用识别结果覆盖设定；【手动解析】保留你的设定（两者的区别就在这里）
- 【自动解析】：自动识调 + 自动识速（导入文件走的就是这条），**会覆盖**当前设定
- 【手动解析】：完全按你设定的调性和 BPM 来，**不做任何自动识别、也不改你的设定**
- 【手动保存】：存成存档。**存过之后，选这一首直接读存档播放，不再解析原文件**——原文件删了、移走、网盘失效都还能弹
- 【曲目库】【设置】两页入口
- 【演奏方式】：
  - **单曲演奏**：只弹当前这首，弹完停
  - **顺序演奏**：弹完自动接曲目库的下一首，循环
  - **随机演奏**：弹完随机换一首
- 【开始演奏】→ 5 秒内切到游戏

演奏时屏幕左上角有一条**悬浮控制条**（可拖动，拖左边的 ≡ 手柄）：

```
≡  上一首   暂停   下一首   停止
```

- **上一首 / 下一首**：在曲目库里切换；已存档的秒切，没存档的会先解析一下
- **暂停**：立刻停手，按钮变成【继续】，再点从原地接着弹（暂停多久都不会错位）
- **停止**：结束本次演奏

**曲目库**

- 【选择音乐文件】导入曲子
- 【从链接导入】粘贴曲谱站（RocoMusic）的分享链接，APP 自己去把那份 MIDI 拿回来；直链（.mid / .wav / .mp3 / .txt）也行。链接在剪贴板里的话会自动填好，你只管点【导入】
- 导入过的都列在这里，**点一下就是当前曲目**（已存档的直接读存档，秒开），长按删除
- 列表里已存档的曲子标「已存档」；顺序 / 随机演奏时**存档过的切换是秒切**，没存档的每次都要重新解析

**练习 / 录制**（首页【练习/录制】进入）

这两个模式都**在游戏里进行**：APP 在后台，声音从游戏出来，APP 在游戏上盖一层透明悬浮层。

**这里有个 Android 上的硬限制，必须先说清楚**：注入的触摸会送到**最上层窗口**，也就是悬浮层自己——
所以"截住你的触摸"和"让游戏收到这一下"是互斥的。唯一的手法是转发的一瞬间把悬浮层临时让开。

因此练习模式有两种，你自己选：

| | 接管触摸（勾选） | 只提示（不勾） |
|---|---|---|
| 能判分吗 | 能 | 不能 |
| 游戏收到触摸 | 由悬浮层转发过去，**声音晚几十毫秒** | **和你没装 APP 完全一样** |
| 记不到的按键 | 转发让开的那一瞬间会漏 | 不适用 |

**录制模式必须接管**——不接管就无从知道你按了哪个键。

- **练习模式**：选一首曲子，点【开始（然后切到游戏）】。屏幕上会有两处提示：
  - **琴键上的计时圈**：圈收到底的那一下按下去就是准的
  - **悬浮条下面的音符滚动列表**：跟悬浮条**同宽**，就在它正下方。接下来要按的音从右往左
    慢慢滑向"现在"这条线，一次预看十几秒内的音；**按掉一个就消掉一个**。
    编号和颜色与琴键上的圈一一对应，同时按的键共用一个编号和颜色
  - 开始前在面板上选 **练习倍速**：0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×
    （和主页面那个「速度」是同一个设置，不会有两个速度打架）
  - 角落显示 `P / G / OK / M / 准确率`
- **录制模式**：点开始后正常弹，弹完点角落的【结束】。这次弹奏会存成**录音**，
  之后能在曲目库里选中它**原样弹进游戏**。

只记录**琴键和时刻**，不录声音。

> 两个前提：①【设置】里开好无障碍服务（每一下都由它转发给游戏，游戏才会出声）；
> ②【设置】里校准过 9 个琴键（要靠坐标判断你按的是哪个键）。

> 代价：转发有一次手势往返（几十毫秒），所以声音会比你按下去略晚一点；
> 判分用的是你按下的时刻，不受这个延迟影响。悬浮层会吃掉手势，所以适合固定键位的界面，
> 不适合需要拖动的画面。

**设置**

权限（悬浮窗、无障碍服务）、【校准琴键】、【试弹一遍】。

**和弦上限**＝同一瞬间最多同时按几个琴键（1 / 2 / 3 / 4 / 5 / 6 / 9）。调大和弦音更完整、更饱满，但也可能更糊。

## 支持什么谱子

| 格式 | 效果 |
|---|---|
| **MIDI（`.mid`）** | 最好。音符是明确的，弹出来就是那首歌 |
| **简谱文本（`.txt`）** | 好。直接写数字，比如 `1 1 5 5 6 6 5-` |
| 音频（mp3 / wav / flac…） | 单音哼唱、钢琴独奏**能弹**，同时响的几个音会一起抓出来当和弦弹。带鼓和唱的整首流行歌还是扒不干净，那种用 MIDI |

音频这条路**同时听好几个音**（不是只听最响的那一个），所以钢琴曲里左手伴奏也会一起弹出来，能按的键基本都用上了。扒谱当然不可能百分百准，听着不对就换【调性】，或者干脆用 MIDI。

## 常见问题

**九个键没全用上？**
乐器中音区只有 `3 4 5 6 7`，do 和 re 只能落在上面那排高八度键上。没用到的键是那首歌本身没走到。

**音区是怎么定的？**
按「离原曲音高最近」自动选。钢琴 MIDI 常常横跨三个八度，而手碟只有一年半，怎么放都得折叠一部分——所以 APP 会把九个键整体挪到让**尽量多的音落在原音高上**的那个八度，而不是死板地跟着最低音走。

**有没有音会被换成别的音级？**
有，但只在**划算**的时候。乐器有些音级在某个八度上根本没有对应的键（比如 `do` 只有高音那一个键），这时如果换一个键能少差 9 个半音以上，就换；否则宁可挪八度也保住音级。所以能原样弹出来的音**绝不会**被换掉。

**弹出来音高不对？**
换上面的「调性」。导入时会自动识调，改完预览会立刻刷新，所见即所弹。

**BPM 要自己填吗？**
不用。导入后会从音符间隔自动识别并填好，也能随时手动改。

**点了没反应？**
确认无障碍服务是开着的。个别游戏会拦截注入的点击，这种目前无解。

**mp3 导进去没几个音？**
正常。从混音里扒旋律不是这个工具能做到的，请换 MIDI。

**有 iOS 版吗？**
没有，也做不了。iOS 沙箱禁止一个 App 向另一个 App 注入触摸，没有 `dispatchGesture` 的等价物；
唯一的可能是越狱加私有 API，而越狱本来就需要一台苹果设备。编译 iOS 还必须用 Mac + Xcode。
本工具的核心能力在 iOS 上不存在，不是移植工作量的问题。
